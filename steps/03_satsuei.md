# 3. プロンプターで撮る
- `python3 tools/url.py genko.json` で URL を作り、本人に渡す。
- 本人への案内（このまま伝える）：
  1. URL をスマホで開く（iPhone は Safari、Android は Chrome）
  2. スマホを立てて、画面側のカメラを顔に向ける（型2は横向き）
  3. 「撮影をはじめる」→ カメラとマイクを許可
  4. 原稿が出る →（ナレーションありなら声が問いを読む）→「ピッ」で撮影開始 → 読む
  5. 読み終えたら「次」と言う（反応しない時は画面の「次」を押す）。言い直したい時は「撮り直す」
  6. 最後に「まとめて保存」→「ビデオを保存」（写真に入る）。または1本ずつ「保存」（ファイルに入る）
- 本人が「撮れた」と言ったら 4 へ。
