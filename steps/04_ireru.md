# 4. 動画を inbox に入れる（本人がスマホのブラウザでする）

## 本人がすること
1. **Safari／Chrome などのブラウザ**で自分のリポを開く（GitHub のスマホアプリではファイルを入れられない）。**main** ブランチのまま → **inbox** フォルダ。Add file が見えない時は、ブラウザのメニューで「デスクトップ用サイト」にする
2. **Add file → Upload files** → **choose your files** → 撮った動画（k1_r1.mp4 など）を全部選ぶ
3. 下の **Commit changes** を押す（「Commit directly to the main branch」のまま）
4. AI に「inbox に入れた」と送る

- **1本 25MB まで**（ブラウザで入れられる上限・GitHub 公式）。プロンプターの録画は1分で約16MB。プロンプターは 25MB に近づくと黄色で知らせる。
- 25MB を超えた動画は入らない。その場面だけプロンプターで短く撮り直す（言うことを2つに分けるなど）。
- 写真アプリで撮った動画は名前に番号が無い。AI がどの場面か聞くので答える。

## AI がすること（順番どおり）
1. 本人の「入れた」のあと、main の inbox を取ってくる：
   - **Claude Code**：`git fetch origin main && git checkout origin/main -- inbox/`（作業ブランチのままでよい。マージはしない）
   - **Codex**：作業中はネットが切れていて取れないことがある。`git fetch` が失敗したら、本人に「この会話を閉じて、Codex で新しいタスクを作り『inbox に入れた。仕上げて』と送ってください」と頼む（新しいタスクは最新の main から始まる）。
2. `ls -la inbox/` で本数と大きさを見る → `python3 tools/make.py --plan` で**どの動画をどの場面に当てるか**を出し、表にして本人に見せる。
3. ⛔ が出たら作らない：
   - 同じ場面が2本 → どちらを使うか聞いて、要らない方を消す（本人 OK のあと `git rm`）
   - 動画が無い場面 → 撮り直してもらう。どうしても飛ばす時だけ、本人の OK をもらって `--allow-missing`
   - 番号なしの動画 → どの場面か聞いて `git mv` で `k{型}_r{番号}.mp4` に名前を直す
   - 型の違う動画 → 前の撮影の残り。本人に聞いて消すか別に置く
4. ✅ だけになったら 5（仕上げ）へ。
