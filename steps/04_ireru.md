# 4. 動画を inbox に入れる（本人がスマホのブラウザでする）
1. ブラウザで自分のリポを開く → **inbox** フォルダ
2. **Add file → Upload files** → **choose your files** → 撮った動画（k4_r1.mp4 など）を全部選ぶ
3. 下の **Commit changes** を押す
- 1本 25MB まで（ブラウザで入れられる上限）。プロンプターの録画は1分で約19MB。写真アプリで撮った長い動画は、場面ごとに分けて撮り直すか、短く切ってから入れる。
- 名前に `_r番号` が無い動画は、名前順に1場面ずつ当てます。1本だけなら、長い無音で場面に分けます。
- AI は本人の「入れた」のあと `git pull` して inbox を見る。
